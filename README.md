# P-Media

Este é um mini projeto de desenvolvimento de uma landing page para a **P-Media**, uma plataforma de jogos web. O layout original para este projeto foi encontrado no Figma.

## 💻 Sobre o Projeto

A **P-Media** é uma plataforma de jogos web em desenvolvimento, onde os jogadores poderão se reunir para jogar seus games preferidos. O foco da plataforma é compartilhar jogos, trocar experiências e auxiliar a comunidade de games a crescer.

Este repositório contém a codificação da interface (Front-end) desenvolvida.

## 🚀 Demonstração

Você pode acessar a versão online e interagir com o projeto através do link do GitHub Pages:
[Acessar P-Media](https://thiagomarcelinovieira.github.io/p-media/)

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias básicas de desenvolvimento web:

*   **HTML5**
*   **CSS3**

## 📂 Estrutura de Arquivos

*   `index.html`: Arquivo principal contendo a estrutura da página.
*   `style.css`: Arquivo contendo a estilização visual do projeto.
*   `ASSETS/`: Diretório contendo as imagens, ícones e outros recursos visuais.
